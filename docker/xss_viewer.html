wadoscope XSS lab viewer — deliberately vulnerable

Paste the DICOM+JSON metadata a PACS returned (e.g. wadoscope retrieve <base> --study <uid> --mode metadata --format json) and watch what a viewer that renders tags as HTML does with a poisoned PatientName. This file is a teaching target — do not ship this pattern.

The “naive” button is the bug: it builds an HTML string from attacker-controlled tag values. The “safe” button is the fix: the same values set via textContent never execute.
